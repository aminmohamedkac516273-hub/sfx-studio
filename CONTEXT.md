# SFX Studio — Context File

## Project Overview
AI-powered SaaS video editing platform for creators, video editors, and universities.
It automatically analyzes video footage and suggests/places matching Sound Effects (SFX).

## Tech Stack
- Next.js 14 (App Router, TypeScript strict)
- Tailwind CSS 3.4 (Dark Mode First)
- Zustand (State Management)
- Framer Motion (Animations)
- Lucide React (Icons)
- Drizzle ORM (Database)
- PostgreSQL
## Custom Components
- UI Components are located in `@/components/ui/` (Button, Badge, etc.)
- Helper `cn` is in `@/lib/utils.ts`

## Design System
- Base background: `bg-zinc-950`
- Cards background: `bg-zinc-900/50`
- Accent Gradient: `from-indigo-500 to-violet-500`
- Theme: Dark Mode Only
